<img width="1919" height="872" alt="image" src="https://github.com/user-attachments/assets/64974f03-8b63-40bd-8d9f-3f1252e3bb29" /># 🎵 Tribute to Zubeen Da

A memorial tribute website dedicated to the legendary singer **Zubeen Garg**, where fans can share their tributes, comments, and memories.

## 🌐 Live Website
Frontend (Vercel):  
https://tribute-to-ourzubeengarg.vercel.app

Backend API (Render):  
https://tribute-to-ourzubeen-da.onrender.com

---

## 🚀 Features

- 💬 Fans can post comments and prayers
- ❤️ Like comments
- 🕊️ Tribute submission section
- 📄 Pagination (3 items per page)
- 📱 Fully responsive design
- ⚡ Fast React frontend
- 🔐 Secure MongoDB backend

---

## 🛠️ Tech Stack

Frontend
- React
- TypeScript
- TailwindCSS
- Vite

Backend
- Node.js
- Express.js

Database
- MongoDB Atlas

Deployment
- Vercel (Frontend)
- Render (Backend)
