# 🎵 Tribute to Zubeen Da

A memorial tribute website dedicated to the legendary singer **Zubeen Garg**, where fans can share their tributes, comments, and memories.

## 🌐 Live Website
Frontend (Vercel):  
https://tribute-to-ourzubeengarg.vercel.app

Backend API (Render):  
https://tribute-to-ourzubeen-da.onrender.com

---

## 🚀 Features

- 💬 Fans can post comments and prayers
- ❤️ Like comments
- 🕊️ Tribute submission section
- 📄 Pagination (3 items per page)
- 📱 Fully responsive design
- ⚡ Fast React frontend
- 🔐 Secure MongoDB backend

---

## 🛠️ Tech Stack

Frontend
- React
- TypeScript
- TailwindCSS
- Vite

Backend
- Node.js
- Express.js

Database
- MongoDB Atlas

Deployment
- Vercel (Frontend)
- Render (Backend)
